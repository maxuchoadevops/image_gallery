📸 Modern Horizontal Image Gallery
Uma galeria de imagens horizontal moderna, elegante e altamente responsiva, construída com foco em UI/UX utilizando apenas HTML5, CSS3 e JavaScript puro. 🚀

✨ Recursos & Funcionalidades
🖼️ Layout Horizontal Fluido: Navegação lateral inovadora e agradável para explorar fotos.

🎯 Navegação Inteligente: Botões laterais flutuantes interativos e suporte a rolagem horizontal com a roda do mouse (mouse wheel).

⚡ Animações Suaves: Transições fluidas usando smooth scroll e efeitos de zoom nas imagens.

🎨 Efeito Visual Premium: Fotos com leve tom de cinza em repouso que ganham cores vibrantes e destaque ao passar o mouse (hover).

📱 Totalmente Responsivo: Adaptado perfeitamente para diferentes tamanhos de tela (desktop, tablets e smartphones).

❌ Zero Dependências: Desenvolvido puramente com tecnologias web nativas, sem frameworks pesados.

🛠️ Tecnologias Utilizadas
HTML5 (Estrutura semântica e moderna)

CSS3 (Variáveis, Flexbox, Grids, Glassmorphism e Gradientes)

JavaScript (ES6+) (Manipulação de eventos e controle de scroll)

Google Fonts & FontAwesome (Tipografia Poppins e ícones modernos)

📁 Estrutura de Pastas do Projeto
Certifique-se de organizar seus arquivos da seguinte forma para que o projeto funcione perfeitamente:

Plaintext
galeria-imagens/
│
├── index.html          # Arquivo principal da página
├── style.css           # Estilos e design moderno
├── script.js           # Lógica de rolagem e interatividade
└── images/             # Pasta contendo as mídias
    ├── image-1.jpg
    ├── image-2.jpg
    ├── image-3.jpg
    ├── image-4.jpg
    ├── image-5.jpg
    └── image-6.jpg
🚀 Como Executar o Projeto
Clone ou baixe este repositório para a sua máquina.

Certifique-se de que a pasta images/ contenha as 6 imagens nomeadas de image-1.jpg até image-6.jpg.

Abra o arquivo index.html em qualquer navegador web moderno (Google Chrome, Firefox, Edge, Safari) ou utilize a extensão Live Server no VS Code.

🎮 Como Usar
🖱️ Com o Mouse: Posicione o cursor sobre a galeria e utilize a roda do mouse (scroll) para navegar horizontalmente pelas fotos.

🖲️ Com os Botões: Clique nas setas flutuantes nas laterais da galeria para mover para a esquerda ou direita.

✨ Interação: Passe o cursor por cima de qualquer foto para visualizar o efeito de expansão e cores reais.
